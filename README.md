# passwordchecker
This is a simple password checker that tests the strength of provided password. It uses my written logic plus top 100k pwn-ed passwords to generate a fair response. It also has an ability to generate strong password that meets all the requirements that a safe password needs.

NOTE: with executable file, you need to put background.png and Top100kPwnedPasswords.txt in the same folder/directory in order for application to fully work. they are provided in Source Code and Files directory. !!! <3
